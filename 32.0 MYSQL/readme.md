# MySQL CRUD

A simple CRUD application built with Node.js, Express, EJS, and MySQL.

## Setup

### Step 1

Install the dependencies:

```bash
npm install
```

### Step 2

Copy `.env.example` and rename it to `.env`.

Update the `.env` file with your MySQL configuration if needed.

### Step 3

Open XAMPP and start **MySQL**.

Open **phpMyAdmin** and import the `products.sql` file.

### Step 4

Start the server:

```bash
nodemon index.js
```

Open the application at:

```text
http://localhost:3000
```
